# 人物照片扫描与候选日记

版本：0.3.2。扫描由用户手动启动，读取系统允许访问的照片；仅授予部分照片权限时只扫描授权范围。人物识别在本机执行，不上传照片进行识别。

## 操作

- 列表和设置中均可开始扫描。扫描进度旁可随时停止，已生成的候选保留。再次扫描跳过已经处理且未变化的照片。
- 每识别一张人物照片就复制到应用私有目录，并按拍摄日期加入候选，立即显示在正式日记列表中。
- 红色蒙版表示候选：左滑保留为正式日记，右滑删除候选，点击可查看、编辑。编辑自动保存仍保持候选，点击“保存”才转正。
- 图片编辑模式下有直接删除按钮，提供撤销；详情查看和编辑模式均可长按拖动图片排序，拖至页面边缘会自动滚动；更多选项仍可从图片菜单使用；不删除系统相册原图。
- 候选保存在本机，转正后才参与 WebDAV 同步。删除候选也不上传删除标记。
- 同日只追加到仍待确认、未打开编辑的候选。已转正、已删除或正在编辑的记录不被扫描器更改；后续同日照片另建候选。
- 每篇日记不设照片数量上限，手动导入、候选转正、合并和同步读取均保留全部照片。详情只解码可见区域及附近的图片。
- 列表长按进入多选，支持批量删除和合并，均提供撤销。合并按时间顺序保留文字和图片，以最早有日期的记录为主体，保留其日期；其余记录标记删除。全部为候选时仍为候选，包含正式日记时合并为正式日记。确认前可预览结果。
- 优先 EXIF 拍摄时间，其次系统相册 DATE_TAKEN；无法确定时放入“日期待确认”，转正前需填写日期。
- 撤销仅在对应记录尚未被后续编辑或同步改变时执行，避免覆盖新内容。

扫描无需一直连续完成。停止会在当前照片处理边界结束；应用进程中断后，下次手动扫描会使用持久化检查点继续。图片解码或导入失败会计数并留待下次重试。首次扫描应保持应用可运行，后台进程可能被系统回收。

## 本地存储

SQLite schema 3 以增量 ALTER TABLE 给 entries 添加 candidate、scan_day；scanned_media 保存来源 URI、修改时间和大小组成的检查点，以及候选/图片关联。检查点和候选记录在同一事务内提交。所有扫描、编辑及确认写入经过同一互斥锁；筛选或编辑中的候选暂时冻结追加。

## 原图与位置

新导入直接复制源文件，不缩放、不转码，保留可访问的 EXIF。系统需要照片访问和媒体位置权限才能提供完整 GPS。日记优先显示手动位置，否则按照片顺序取首个有效 GPS。云同步保存照片坐标并流式传输原文件，无 12MB 图片限制。

设置中的“恢复旧照片原图并补全定位”先检查已知来源，再扫描获准访问的相册。通过源文件 SHA-256 或重现历史 JPEG 编码后的 SHA-256 精确匹配，不按日期或相似外观推测。匹配后复制原图，以新文件名原子更新引用及坐标，避免缓存与同步沿用旧文件；候选仍为候选，正式日记标记待同步。旧文件保留，未匹配照片不变。保存时解析替换别名，防止旧编辑内容重新引用压缩图。停止在当前图片边界生效，已提交结果保留；不会改日记时间。


## 地点选择、日期和分享

位置保存经纬度、名称和详细地址，兼容原先只有坐标的记录。0.6.0 的地点路由与高德接入见 [地点服务](place-services.md)，以下 0.5.1 节保留上一版开放地图实现记录。搜索手动提交，旧记录打开时按需解析并缓存，解析不移动原始 GPS。选择器默认提供当前位置；用户明确选择确认后才修改日记位置。允许修改显示名称为店名，保留所选坐标；拒绝定位权限不影响文字搜索。查询失败或超时可重试，原坐标不丢失。异步结果有会话和查询版本保护，取消或切换日记后不写回错误条目。

日记编辑页的日期时间按钮、标题日期和更多菜单均可打开日期/24小时制时间选择器。两步都确认才写入 createdAt；取消不改数据。候选同步更新所属日期，列表随新日期排序，文字、图片和位置保留。

全屏图片右上角分享按钮使用系统 ACTION_SEND，只分享当前页原文件，不重新编码。FileProvider 只暴露应用 photos 子目录，为接收 App 授予临时只读访问，附带 MIME 和 ClipData。目标 App 由用户在系统面板选择。


### 0.5.1 地点搜索修复

手机系统 Geocoder 正向搜索对部分词返回 unknown error，不能把短暂的系统接口成功等同于稳定的店铺搜索。改为手动提交到 Photon（默认 https://photon.komoot.io/），不需要 Key；可在设置中更换兼容 Photon 的 HTTPS 服务。发送关键词及可选的附近位置偏置，不限制跨城市搜索。结果是 WGS84，按 GeoJSON 经度、纬度顺序读取，保存来源并显示 OpenStreetMap 署名。

进程共享请求队列间隔至少约 1.1 秒；取消搜索会取消 HTTP 请求。成功结果缓存 7 天，空结果缓存 5 分钟，最多约 128 个查询。无收录、连接失败、超时、HTTP 限流和格式错误有不同提示。公共实例仅用于少量手动搜索，较大规模部署应使用自己的或供应商提供的兼容服务。开放地图的店铺覆盖取决于社区收录。

服务与 API 说明：https://github.com/komoot/photon 、https://github.com/komoot/photon/blob/master/docs/api-v1.md 。
